# Subject

A high-fidelity iOS mobile app screenshot mockup for "よりそい つながる".
The first onboarding screen — "ようこそ" / Welcome.

This is the user's first impression of the app, so it must convey:
**信頼感・温かさ・大人の安らぎ・静けさ**.

The aesthetic is editorial Japanese magazine applied to a mobile app:
Kinfolk / 暮しの手帖 / MUJI catalog. NOT children-book.

# Screen layout (top to bottom)

## 1. iOS Status Bar
- Time: **9:41** in SF Pro semibold, color #2A2622
- Right: signal bars (3/4), WiFi, battery (~60%)
- Background: cream paper (#FAF6EE)
- All icons subtle and small

## 2. Top right "スキップ" link
- Position: top-right corner, padding 16px
- Text: "**スキップ**" in Yu Gothic 12px, faint gray (#A39B96)
- No box, just text

## 3. Hero image (large, top-center, ~50% of screen height)
- A large vertical hero image with rounded corners (28px radius)
- Margin: 28px on left/right and ~24px from top
- Aspect ratio of the image: 4:5
- Content: **a quiet morning still life** — a wooden window sill at dawn,
  with a small ceramic teacup (terracotta glaze), a folded linen cloth,
  and a single green leaf. Soft warm window light from upper-left.
  Background outside the window is a faintly out-of-focus cream curtain
  with a hint of trees.
- The image style is **photographic illustration** (Kinfolk magazine aesthetic),
  warm muted tones (honey, cream, terracotta, moss green)
- Subtle soft shadow under the image

## 4. Eyebrow text (below the hero image)
- Small text: "**ようこそ**" in Yu Gothic Medium 11px,
  warm sepia (#7E5A40), letter-spacing very wide (0.24em)
- Centered horizontally

## 5. Main title (Yu Mincho serif)
- Text: "**よりそい つながる**" in Yu Mincho 30px Regular,
  color #2A2622, letter-spacing wide (0.08em)
- Centered horizontally
- Padding top: 14px after eyebrow

## 6. Description text (Yu Gothic body)
- Three lines centered, color #4F4843, font 15px, line-height 1.95
- Content (verbatim):
  "**ここは、同じしんどさを抱える人と、**
  **そっと、つながれる場所です。**
  ***( blank line )***
  **話さなくても、構いません。**
  **ただ、ここに居るだけで、大丈夫です。**"

## 7. Bottom area (fixed at the bottom, ~140px)
- Top border (subtle line in #ECE2D2)
- Padding: 24px

### 7a. Progress dots (centered, above the button)
- 6 small dots in a horizontal row, gap 8px
- First dot: filled rectangle (active state) — width 22px, height 6px,
  rounded, terra-500 (#A47556)
- Other 5 dots: small circles, diameter 6px, gray (#D6C8B2)
- Margin bottom: 20px

### 7b. Primary CTA button
- Full-width terracotta pill button
- Background: solid terra-500 (#A47556)
- Text: "**はじめる**" in Yu Gothic Medium 16px, color cream (#FAF6EE),
  letter-spacing wide (0.06em)
- Padding: 16px vertical
- Rounded: 999px (full pill)
- No shadow (clean flat)

## 8. iPhone home indicator (very bottom, ~34px)
- A thin horizontal black bar, centered, ~134px wide

# Composition
- Vertical iPhone screen (9:19.5).
- Hero image dominates the upper half.
- Text content sits in the middle.
- Single CTA button at the bottom.
- Very spacious — generous breathing room everywhere.

# Color palette (strict)
- Background: cream paper #FAF6EE
- Hero image colors: warm honey wood, cream linen, terra teacup, moss leaf
- Text primary: #2A2622
- Text secondary: #4F4843
- Text faint: #A39B96
- Primary terracotta: #A47556

# Typography (must be accurate)
- Welcome eyebrow: Yu Gothic Medium 11px, wide letter-spacing
- Main title "よりそい つながる": Yu Mincho 30px Regular, wide letter-spacing
- Description: Yu Gothic 15px Regular, line-height 1.95
- Button text: Yu Gothic Medium 16px
- Skip link: Yu Gothic 12px

# Style references
- Real apps: Day One Journal welcome screen, Stoic Journal onboarding,
  Things 3 first run, Bear Notes welcome
- Magazines: Kinfolk feature openers
- AVOID: Snapchat-style onboarding, kids' game splash screens,
  ride-share app welcome screens

# Avoid
- ANY mascot characters in this welcome screen (the hero image is a still life,
  no animals, no people, no faces)
- Generic stock photography
- Bright pinks, neon highlights
- Emoji decorations (no ✨🌸)
- AI-garbled Japanese text (must be exact strings as specified above)
- Multi-button layouts (only ONE CTA button at the bottom)
