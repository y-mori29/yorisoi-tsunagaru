## 共通仕様（全画面）

- **画像サイズ**: 1170 × 2532 px（iPhone 14 Pro）
- **アスペクト比**: 9:19.5（縦長）
- **出力先**: `assets/screens/NN-name.png`
- **スタイル**: iOSアプリスクリーンショット / 編集系（MUJI / Kinfolk）
- **カラー**: くすみテラコッタ × モスグリーン × グレイッシュパープル
- **タイポ**: 游ゴシック / 游明朝 / Inter
- **共通要素**:
  - iOS Status Bar（9:41 / signal / WiFi / battery）
  - App Header（タイトル + アクション）
  - Bottom Nav（5タブ）または Bottom CTA
  - iPhone home indicator

## 使い方

1. 該当する md を開く
2. Subject 〜 Avoid まで全文を画像生成ツールにコピペ
3. 「Text (verbatim)」と記載された日本語テキストは **正確に** 描画するよう指示
4. 出力された PNG を `assets/screens/` に配置

## 推奨ツール

| ツール | 強み | 注意 |
|---|---|---|
| **Gemini CLI / nano BANANA 2** | 日本語テキスト描画が比較的安定・4K対応 | API クォータ・PTYエラー注意 |
| **Codex CLI / GPT-Image-2** | Plus 枠内で動作・スタイル制御安定 | テキスト描画は完全ではない |
| ChatGPT (Image) | 手動操作・iOS UI生成に強い | 日本語ぼやけることあり |
| Midjourney | 美術性高い・iOSスクショ生成も可 | 日本語テキスト描画は弱め |
| **Figma + AI plugin** | 後修正前提なら最適 | 一手間 |

## 日本語テキスト描画の現実

AI画像生成の日本語は **完璧ではない** 場合が多いです。各 md には「Text (verbatim)」として再現してほしい文字列を明示しています。生成結果が崩れた場合の対応：

**選択肢A：軽微な崩れは許容**
- ヘッダー・本文程度の短文ならズレを許容
- モック検討用としては十分

**選択肢B：Figma で後修正**
- 生成画像を Figma に取り込み
- 文字部分だけ上から正しいテキストを重ねる
- これが最も実用的

**選択肢C：英訳して生成→日本語に置換**
- 英語版でレイアウトと装飾を生成
- 日本語文字は後でPhotoshop/Figmaで差し替え
