## きっかけ

v2 オンボーディングプロンプトの「同じしんどさを抱える人とそっと繋がれる場所です」という文言が、入り口でユーザーに「あなたはしんどい人ですね」というラベルを貼る行為になっていた。

慢性疾患を抱える方の多くは、自分を「しんどい人」と認識していない・したくない・今日はそう感じていない。入り口の最初の文言でそう定義されることの重さが、設計から抜けていた。

森さん指摘（2026-05-17）：
> 「私はしんどいんだ」と認識させられてしまうような表現が、まず入り口にあるのは不適切と感じる。もっとホスピタリティと寄り添う心を持った、カウンセラーのような形でいてほしい。ただ、その方を病の人、病んだ人、しんどい人と扱うのは良くないと考えている。

## 核となる原理

> **「ここに、ただ、いていいです。」**

何かをしなくていい。語らなくていい。誰かと繋がらなくてもいい。
存在することだけが、すでに歓迎されている。

これは「カウンセラーのような」という指示と完全に一致する。
良いカウンセラーは「何があったんですか」と聞かない。
「来てくださって、ありがとうございます」と言う。

## 統合される 4 つの本質（森さんが「全て大事」と言った 4 つ）

1. **気にかけている気配** — 何もしなくても、誰かが気にかけている
2. **「あなたのままで」** — 状態に関わらず、変わらない態度
3. **無理しなくていい設計** — 沈黙・距離・休みが、すべて許される
4. **同じ気持ちの存在** — 似た思いの誰かの声に、いつでも出会える

→ 束ねるのが「ただ、いていい」という原理。

## オンボーディングの再設計

### Before（旧・NG）
> ここは、同じしんどさを抱える人と、そっと繋がれる場所です。

### After（採用方向）
> **ここまで、来てくださって、ありがとうございます。**
> 何もしなくて、大丈夫です。
> ただ、いてください。

## ヒーローイメージの再設計

**旧**：窓際のコップ・布巾・葉っぱ → 「優しさのアイコンを演出した広告写真」になっていた

**新方向**：

| 案 | イメージ | 効く理由 |
|---|---|---|
| **A** | 夜明けの抽象グラデーション（クリーム→淡いピンク→淡い水色、文字以外なし） | 「世界はもう、あなたを迎える準備ができている」気配 |
| B | 遠い風景（朝靄の道・湖・丘、人物も道具もなし） | 「ここではない、もうひとつの場所」感 |
| C | 余白そのもの（水彩の滲み・和紙テクスチャ・床の間の軸風） | 「画」ではなく「気配」。日本の余白美 |

**採用**：A（夜明けの抽象グラデーション）
理由：文字を最も静かに支える。B は観光地っぽくなるリスク、C は瞑想アプリ寄りすぎる。

## これが全体に効く（機能のデフォルトが変わる）

| 要素 | 旧（活動を促す） | 新（存在を肯定する） |
|---|---|---|
| ホーム初期 | フィードに投稿が並ぶ | 「今日、ここにいる人たち」の気配だけ |
| 投稿ボタン | 中央・大きい | 控えめ・脇に置く |
| 通知 | 「届きました！」プッシュ | 静かに溜まる「お便りボックス」 |
| プロフィール | 名前・自己紹介を促す | 任意、空のままでも違和感がない |
| となりさがし | 「3つの質問に答えて」 | 「気が向いたら、どうぞ」 |
| 滞在の既定 | 何かする | 見るだけ・閉じるだけで完結 |

→ 「行動を引き出すSNS」ではなく「**いるだけの場所**」。
GRAVITY を超えて、もっと静かなアプリになる。

## NG ワード集（禁則 — 全画面で適用）

ユーザーをラベリングする以下の語は、特にトップ画面・オンボ・空状態・通知の文言で **使用禁止**：

- しんどい / つらい / 苦しい / 悲しい
- 病気 / 病人 / 患者（※ヘルプ等の技術文脈ではOK）
- 闘病 / 戦う / 戦士
- 弱い / 弱った / 落ち込んだ
- 「悩みを抱える」「不安を抱える」など、状態を断定する表現

代わりに使う：
- 「来てくれた」「ここにいる」「ゆっくり」「そっと」「ただ」「いつでも」

### 2. 通知の自然消滅（24時間）

「お便りボックス」方針自体は良いが、**通知が溜まりすぎることが負担になる方がいる**ため、初期設定で **24時間で自然に消える** 仕様にする。

- 対象: ユーザー通知（声・反応・コメント・お隣さんになった）→ 24時間で自然消滅
- 例外: 「おまもりレポート」など運営からのシステム通知 → 別ルール（手動で消すまで残る）
- UI: 通知画面の控えめなフッターに「お便りは、24時間ほどで、自然に消えていきます」と明示
- 設定: ユーザーが延長・無効化できる（設定画面の「お便りを受け取る」内）

### 3. 語彙修正: となりさん → お隣さん

「となりさん」より「お隣さん」のほうが温かく、日本語として自然。  
全プロンプト・全画面で一括置換：
- となりさん → お隣さん
- となりさがし → お隣さがし
- ホームの segment tab "となり" → "お隣"
