# 「よりそい つながる」デザインシステム

作成日: 2026-05-16
位置づけ: `docs/design-system-gravity.md` を医療版に翻訳したもの。**モックの直接の設計図**。CSS変数・コンポーネント仕様まで踏み込んで定義する。

---

## 0. このプロダクトのデザイン原則

1. **医療っぽさを徹底排除**（白衣・聴診器・カルテ・点滴・赤十字・冷たい青を使わない）
2. **「治す・闘う」ではなく「ともに在る」**（戦闘メタファー禁止）
3. **常に何かのビジュアルがある**（空きグレー枠ゼロ）
4. **数で順位がつかない**（フォロワー数・いいね数を全面非表示）
5. **能動的に動かなくても誰かが来てくれる**（受動的接続を全面に出す）
6. **拡散しない**（リポスト機能を作らない）
7. **3ステップで始まる**（オンボの摩擦を最小化）

## 1. 世界観（World）

### 1-1. メタファー（宇宙からの転換）
GRAVITYの「宇宙・星」を **「庭・木漏れ日・小さな生き物たちの森」** に置き換える。

理由：
- 宇宙メタファーは医療文脈で違和感（距離感が冷たすぎる・近未来すぎる）
- 「庭」「森」は身近で温かい・植物の成長＝回復のメタファーとしても効く
- 患者が住む「**家のすぐそばの安心できる場所**」という感覚を狙う

### 1-2. 機能語彙の翻訳マップ

| GRAVITY | よりそい つながる | 意図 |
|---|---|---|
| 宇宙（ホーム） | **おうち** | 帰ってこられる場所 |
| 星（投稿） | **こえ** | 声に出さなくても声になる |
| 流れ星（質問） | **そっと届く声** | 押し付けず、そっと届く |
| 心友（フォロー） | **となりさん** | 隣に座ってくれる人、の意 |
| 心友ノック（マッチ） | **となりさがし** | 「近い人」を探す |
| プラネット（コミュ） | **おうち（疾患別）** | UCのおうち、クローンのおうち など |
| みつける（探索） | **おさんぽ** | 散歩感覚で他の人のページに迷い込む |
| 星の予報（レコメンド） | **きょうのきざし** | 「気づき」のニュアンス |
| 宇宙通話（音声） | **(初期非実装)** | リスク高・後日 |
| 通知 | **おたより** | 手紙が届くニュアンス |

### 1-3. キャラクター（マスコット）
GRAVITYの中性的宇宙人キャラを **やわらかい森の動物たち** に置き換える。

公式マスコット候補：
- **🌱 もか（うさぎ）** — メインマスコット。聞き役・案内役
- **🍞 ぱお（くま）** — 静かに隣にいる役・空状態に登場
- **🌿 そら（猫）** — 「おさんぽ」担当・気まぐれに導く
- **🌸 ふう（小鳥）** — 通知・お便り運び役

3〜4キャラを **「森の住人たち」** として配置。
ユーザーは自分のアバターとして同じ動物世界観のイラストアバターを選ぶ（性別・年齢を匂わせない）。

### 2-2. 使い分け原則
- **ベース白**ではなく **bg-cream (#FFFBF5)** を必ず使う（純白は冷たい）
- **黒テキスト禁止**。`--text-primary` (#2E2A2A) を使う（暖グレー）
- **赤は使わない**。エラー・警告も `--warm-warning` のオレンジ寄り
- **ピュアブルーは使わない**。情報色は `--warm-info` のくすみブルー
- グラデーションは **peach → matcha** or **peach → lavender** の柔らかい流れ

## 3. タイポグラフィ

### 3-1. フォントスタック
- 本文：`var(--font-jp)`（ヒラギノ角ゴ）
- 見出し・ロゴ：`var(--font-jp-round)`（Zen Maru Gothic / 丸ゴ）

### 3-2. スケール

### 3-3. コピートーン
- やわらかい・命令しない・「いいね」ボタンも「うん」「そっか」のような言葉に
- 例：
  - 「投稿」→「こえを置く」
  - 「フォロー」→「となりさんになる」
  - 「いいね」→「**うん**」「**そっか**」「**ありがと**」（共感スタンプ）
  - 「通知」→「おたより」
  - 「設定」→「**いろいろ**」
  - 「ログイン」→「**おかえり**」
  - 「ログアウト」→「**いってきます**」（ログインは「おかえり」）

## 4. アバター・キャラクター仕様

### 4-1. ユーザーアバター
- **動物モチーフのプリセット 12種**：うさぎ・くま・ねこ・ことり・ハリネズミ・りす・たぬき・きつね・ひつじ・ふくろう・かめ・くらげ
- 各動物に **色違いバリエーション 4種**（白系・茶系・グレー系・パステル系）
- 実写・自撮りは **アップロード不可**（プリセットのみ）
- 表示：円形クロップ・周囲にやわらかいglow
- サイズ：32 / 48 / 64 / 96 / 128px

### 4-2. アバター装飾（飾り）
- 帽子・リボン・葉っぱの冠・小さな花・しっぽリボン など
- ガチャや課金はせず、**ログイン日数・投稿数で貯まる「ぽいんと」で交換**
- 装飾は周囲にレイヤー重ね

### 4-3. 公式マスコット
- **もか（うさぎ）** ピンクベースの淡い色
- **ぱお（くま）** クリーム色・体型ふっくら
- **そら（猫）** 抹茶グリーン・しっぽが長い
- **ふう（小鳥）** ラベンダー色・小柄

それぞれ 5〜6 ポーズ（喜ぶ・読んでる・寝てる・歩いてる・手を振る・空を見上げてる）

## 5. レイアウト

### 5-1. グリッド・余白
- モバイルファースト（width: 100% / max-width: 480px / margin: 0 auto）
- 左右パディング：20px
- セクション間：24〜32px
- カード間：16px

### 5-2. ボトムナビ（5タブ）

| Tab | アイコン | ラベル | 内容 |
|---|---|---|---|
| 1 | 🏠 おうち | ホーム | タイムライン |
| 2 | 🌿 おさんぽ | 探索 | 他ユーザー巡り |
| 3 | ➕ **おく** | 中央・特別 | こえを置く（投稿） |
| 4 | 💌 おたより | 通知 | 反応・となりさん |
| 5 | 🌱 わたし | プロフィール | 自分のページ |

中央の「おく」ボタン：
- 直径 56px・ピーチグラデ円
- 浮いてる感（drop-shadow）
- 軽く脈打つアニメ

### 5-3. ヘッダー
- 高さ 56px
- 左：戻るボタン or 画面タイトル
- 中央：マスコットの小さなアイコン（ブランド表示）
- 右：アクション（共有・設定など）

## 6. コンポーネント仕様

### 6-1. ボタン

```css
/* プライマリ */
.btn-primary {
  background: linear-gradient(135deg, var(--peach-200), var(--peach-400));
  color: var(--text-on-color);
  font: 500 16px/1 var(--font-jp-round);
  padding: 14px 28px;
  border-radius: var(--radius-pill);
  box-shadow: var(--shadow-card);

.btn-primary:active { transform: scale(0.97); }

/* セカンダリ */
.btn-secondary {
  background: var(--bg-card);
  color: var(--peach-700);
  border: 1.5px solid var(--peach-200);
  /* 他はプライマリと同じ */
}

/* ゴースト */
.btn-ghost {
  background: transparent;
  color: var(--text-secondary);
  border: none;

```

### 6-2. 投稿カード（こえカード）

```
┌─────────────────────────────────┐
│  🐰 もかさん          3分前  ⋯  │  ← ヘッダー
│                                 │
│  きょうは朝からなんだか           │
│  気持ちが落ち着かなくて。         │  ← 本文（16px・行間1.75）
│  そっと深呼吸してみました。       │
│                                 │
│  [ そっと添えられた写真 ]         │  ← 画像（任意）
│                                 │
│  🌸 うん 12  💭 3                │  ← リアクション・小さく
└─────────────────────────────────┘
```

- 背景：`var(--bg-card)`
- 角丸：`var(--radius-lg)`（24px）
- shadow：`var(--shadow-card)`
- パディング：20px
- 投稿者ハンドル：18px W500
- 経過時間：12px `var(--text-tertiary)`
- リアクション数：12px W400 `var(--text-secondary)`

### 6-3. 共感スタンプ（5種）
| スタンプ | 言葉 | 使うシーン |
|---|---|---|
| 🌸 | うん | 共感 |
| 🌿 | そっか | 受け止め |
| ☁️ | きいたよ | 既読的 |
| 🌱 | だいじょうぶ？ | 心配（控えめ） |
| 🍵 | ありがと | 感謝 |

- スタンプは小さく、押下数を派手に見せない
- 「**何個押されたか**」は投稿者にだけ通知で届く（他人には見えない）

### 6-4. 入力欄（こえを置く）

- 背景：`var(--peach-50)`
- ボーダー：1px solid var(--border-soft)
- フォーカス時：ピーチグラデの薄い枠が浮かぶ
- プレースホルダー：「**いまのきもち、ここに置いてみる？**」
- 文字数カウンタ：右下に小さく（オーバー時のみ色変化）

### 6-5. 「そっと届く声」カード（流れ星に相当）

```
┌─────────────────────────────────┐
│  🌸 ふわっと、声が届いたよ        │  ← ヘッダー
│                                 │
│  「最近、ちゃんと眠れてる？        │  ← 本文
│   私はあんまり眠れてなくて…」      │
│                                 │
│  ─ あるとなりさんより             │  ← 匿名表記
│                                 │
│  [ そっと返す ]  [ そっと閉じる ]  │  ← ボタン2つ
└─────────────────────────────────┘
```

- カード自体に **きらめき装飾**（角に小さな花・星）
- 24時間で消える表示（タイマーは目立たせない・小さく）
- AI返信補助ボタン：「ことばを手伝ってもらう」

### 6-6. 通知バナー

- 画面上端から下にスライドイン（280ms ease-out spring）
- 4秒で自動消滅
- マスコットアイコン + 1行メッセージ
- 例：「🐰 となりさんから、そっと声が届いたよ」

### 6-7. オンボーディングカード
- フルスクリーン・3ステップ
- 各ステップにマスコットが大きく登場
- プログレスドット（3個・ピーチ色で進捗）
- 「あとで」ボタンも常に表示

## 7. モーション・アニメーション

### 7-1. イージング
```css
--ease-spring:  cubic-bezier(0.34, 1.56, 0.64, 1);
--ease-soft:    cubic-bezier(0.4, 0, 0.2, 1);
--duration:     220ms;
```

### 7-2. 具体例
- 投稿成功 → カードがふわっと浮かびあがる（fade + translate-up 8px）
- 共感スタンプ → アイコンが一瞬大きくなって戻る（scale 1.2 → 1.0）
- 「そっと届く声」到着 → 画面上に小さな花びらが舞う・通知バナー降りる
- ローディング → マスコットがゆっくり呼吸（scale 1.0 → 1.04 → 1.0 を 2.4s で繰り返し）
- 画面遷移 → fade + 微スライド（突然変わらない）

### 7-3. 常時動いている要素
- マスコットが **ゆっくり呼吸**
- 背景の小さな葉っぱドットがふわっと揺れる
- 「+ おく」ボタンが **2秒に1回 軽くglow**

## 8. 画面別仕様（モック対象）

### 8-1. オンボーディング（3ステップ + 最初のひとこと）

| step | 内容 |
|---|---|
| 1 | ようこそ。マスコットもかが「ここはあなたのとなりに、おなじしんどさをかかえる仲間がいる場所だよ」と挨拶 |
| 2 | ハンドル名（仮ニックネーム可）入力 |
| 3 | 動物アバター選択（12種 × 4色） |
| 4 | 性別・年代（任意・スキップOK） |
| 5 | 最初のひとこと「はじめまして」「最近◯◯がつらい」等の例文付き |
| 6 | 完了。すぐにマスコットからの反応が届く |

性格診断・疾患選択は **後でやれる**（強制しない）

### 8-2. ホーム（おうち）
- 上部：ヘッダー「おうち」・右に通知ベル（バッジ付き）
- タブ：**みんな** / **となりさん** （切替）
- フィード：投稿カードが縦に並ぶ
- 右下：FAB「+ おく」（中央タブと同機能・どっちでも投稿できる）
- 一番上に **「きょうのきざし」カード**（運営や AI からの問いかけ・1日1個）

### 8-3. 投稿モーダル（こえを置く）
- 下からせり上がる bottom sheet
- 入力欄・画像追加・公開範囲切替（みんな/となりさん/しずか）
- 「**しずか**」モード：自分だけ見える日記モード（公開しない・記録だけ）
- 投稿ボタン：「**そっと置く**」（プライマリ・大きめ）

### 8-4. そっと届く声（流れ星受信）
- カード形式・通知から遷移
- 1件ずつ表示・スワイプで次へ
- 返信 or 閉じる
- 「ことばを手伝ってもらう」ボタン（AI下書き）

### 8-5. となりさがし（マッチング）
- 16性格診断の前段：「3つの質問」で軽く性格を把握（簡易版）
- 結果に基づいて「考え方が近い人 3名」を提示
- 「**ノックする**」ボタン → 相手に通知

### 8-6. おさんぽ（探索）
- ランダムに他ユーザーのページに迷い込める
- 「**ぱおっとおさんぽ**」ボタンで次の人へ
- 共感したら「うん」を押す or となりさんになる

### 8-7. プロフィール（わたし）
- 上：アバター大表示・ハンドル名・自己紹介（短く）
- 中：性格診断バッジ・所属している疾患ルーム（あれば）
- 下：自分の投稿履歴・スタンプ履歴

### 8-8. 通知（おたより）
- リスト形式・マスコットアイコン付き
- 「🐰 ◯◯さんがあなたのこえに『うん』してくれたよ」など
- 既読/未読を区別（ピーチドット）

### 8-9. 設定（いろいろ）
- アカウント
- 通知
- プライバシー・公開範囲のデフォルト
- ブロックリスト
- データのエクスポート（医療データを後でPHRに渡す導線）
- ヘルプ・お問い合わせ

## 9. 心理的安全性の仕掛け（GRAVITY継承）

| 仕掛け | よりそい つながるでの実装 |
|---|---|
| フォロワー数非表示 | プロフィールに数を出さない・自分の画面でも非表示 |
| いいね数の非他人公開 | スタンプ数は **投稿者のみ通知** で気づく |
| リポスト機能なし | そもそも作らない |
| 公開範囲3段階 | みんな / となりさん / しずか（自分だけ） |
| 検索拒否 | 設定で ON/OFF |
| AI事前モデレ | 投稿前にチェック・性的/誹謗/医療デマ/自殺示唆 |
| 自殺示唆検知 | 「いのちの電話」「よりそいホットライン」連絡先を **静かに** 通知 |
| 通報・ブロック | どこからでも・ワンタップ |
| 月次セキュリティレポート | 「**おまもりレポート**」として公式が月1回投稿 |

## 10. 「医療っぽさ」排除チェックリスト

モック制作中・画像生成中に確認すべきNG：

- ❌ 白衣・聴診器・カルテ
- ❌ 点滴・注射器・薬瓶（多用）
- ❌ 赤十字・救急車・病院アイコン
- ❌ 純白・冷たい青・濃いグレー
- ❌ 折れ線グラフ・数値の大きな表示
- ❌ 「治療」「克服」「闘病」「症状」の語彙を前面に出す
- ❌ 「ビフォー → アフター」構図
- ❌ 「がんばろう」「諦めない」系の押し付けコピー
