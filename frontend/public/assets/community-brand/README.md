# よりそい つながる コミュニティ版 画像素材

このフォルダは、公開コミュニティUIで使う水彩トーンの画像素材置き場です。

## 直接使う素材

- `paper-bg-v2.png`: ページ背景
- `home-gathered-voices-v1.png`: ホーム冒頭の「いろいろな声が集まる」挿絵
- `room-quiet-place-v1.png`: 部屋詳細の安心感を出す挿絵
- `composer-notebook-v1.png`: 投稿画面・投稿完了画面の挿絵
- `empty-soft-room-v1.png`: 空状態の挿絵

## 切り取り前提の素材

- `brand-asset-sheet-v1.png`: 紙片、葉、ノート、小物、反応モチーフなど
- `animal-avatar-sheet-v1.png`: アバターの元シート

## 個別アバター

`avatars/` に8種類の個別PNGがあります。投稿カードではこちらを優先して使います。

## 注意

- 画像内に文言は入れない方針です。病気名、症状、部屋名、投稿文はHTML/CSS側で管理します。
- 追加で切り出した素材は `crops/` を作って保存してください。
- 生成プロンプトと画面ごとの使い方は `docs/design/yorisoi-community-asset-manifest-20260622.md` を参照してください。
