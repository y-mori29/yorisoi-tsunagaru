## 2. データモデル

今回すぐに新しい大規模データモデルは追加しない。まずUIの意味づけを直す。

ただし、後続検証のために以下の観測項目を残せると良い。

```text
UXFeedbackIssue
  app: "tsunagaru" | "3button-line" | "cross"
  screen: string
  source: "survey" | "meeting" | "qa"
  issueType: "understanding" | "navigation" | "trust" | "input-load" | "visual"
  evidence: string
  priority: "P0" | "P1" | "P2"
  proposedAction: string
  status: "planned" | "implemented" | "verified"
```

```text

```


## 3. 共通方針

- 機能追加より先に、既存操作の意味を分かるようにする。
- 押せるものは押せる見た目、押せないものは状態表示の見た目にする。
- 「やさしい言葉」は残すが、最初の操作名だけは普通の言葉で補う。
- 入力前に安心を出す。特に投稿は、表示先・公開範囲・編集/削除の可否が見えないと不安が残る。

## 4. 機能別設計

### 4.1 つながる: 探す操作のフィードバック

目的:
検索や病名クリック後に、何が変わったかを即座に伝える。

主な画面:
- `/find`
- `/home`
- `/rooms`

設計:
- 選択中の病気・症状・不安を画面上部に固定表示する。
- 結果エリア見出しを「選んだ内容に近い声」に変える。
- 件数や代表タグを表示する。ただし少なさが目立つ数字演出は避ける。
- チップは「選択中」「追加できる」「情報だけ」を見た目で分ける。

### 4.2 つながる: 投稿前プレビュー

目的:
投稿への心理的不安を下げる。

主な画面:
- `/post`
- `/rooms/[id]`
- `/home`

設計:
- 送信前に「この声はこう見えます」プレビューを出す。
- 公開範囲ごとに、表示先を1文で示す。
- 病名やハンドルネームがどう表示されるかを明示する。
- 投稿後に「どこに置かれたか」と「あとから見直せる場所」を表示する。

### 4.3 3ボタン: 初回ホームの重みづけ

目的:
最初に何をすればよいかを明確にする。

主な画面:
- `/`

設計:
- `はなす` を一番大きく、最初の主操作にする。
- `ふりかえる` と `みせる` は「記録がたまると使える」補助として下に置く。
- 記録がない空状態では、「まず1件残す」以外の選択肢を増やしすぎない。
- `本人の記録` のような押せそうで押せないチップは削除、または説明ラベルへ変更する。

### 4.4 3ボタン: はなす入力の整理

目的:
録音以外の入力方法でもつまずかないようにする。

主な画面:
- `/simple/record.html`

設計:
- 録音を主役に保つ。
- 手入力は「録音できない時はメモで残す」として、録音直下に見える導線で出す。
- AI会話は「何を書けばいいか迷う時」として、さらに補助に下げる。
- 入力項目は一度に全部出さず、最初は本文だけでも進める。

### 4.5 横断: つながると3ボタンの接続

目的:
WebサイトとLINEアプリが別サービスに見える問題を減らす。

設計:
- つながる側に「診察で聞いたことを残したい時はLINEで記録」の説明導線を置く。
- 3ボタン側に「次の診察まで不安な時は近い声を読む」の説明導線を置く。
- ただし、初回画面に相互リンクを出しすぎない。主操作の邪魔をしない位置に置く。

## 5. 外部連携

- つながるはNext.js。`pnpm@10.13.1` 指定。
- 3ボタンLINEはExpress静的HTML中心。Cloud Runの公開/タグ切替は別判断。
- LINE実ログイン、LIFF実値差し替え、Cloud Runトラフィック切替は今回の計画作成では実施しない。

## 6. 現行実装との差分

| 差分 | 対応方針 | 優先度 |
|---|---|---|
| つながるで操作後の変化が伝わりにくい | 選択中状態・結果見出し・チップ状態を整理 | P0 |
| 投稿後の表示イメージが見えず不安 | 投稿前プレビューと公開範囲説明を追加 | P0 |
| 「置く」「吐き出す」が初回で伝わりにくい | 初回は普通の言葉を併記 | P0 |
| 3ボタンが並列で、記録前は意味が重い | はなす主役、他2つは記録後導線として再配置 | P0 |
| 手入力導線が見つけにくい | 録音直下に見える補助導線として出す | P0 |
| 文字が小さい/情報量が多い | 最小フォント基準と1画面情報量を見直す | P1 |
| WebとLINEが別物に見える | 相互導線と説明を追加 | P1 |
