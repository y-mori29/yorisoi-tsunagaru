# Fable 5 UX監査パック（森さん用の使い方メモ）

Cursor（Fable 5）に「よりそい つながる」のUX監査・そぎ落とし計画を依頼するための自己完結パック。2026-07-02作成（Claude Code）。

## 使い方（3ステップ）

1. **Cursorで `medicanvas/yorisoi-tsunagaru` フォルダを開く**（Projects全体ではなくこのリポジトリだけ。モデルは Fable 5 を選択）
2. 最初のメッセージに次を貼る:

   > `docs/handoff/2026-07-02-fable5-ux-audit/00-request.md` を読んで、そこに書かれた進め方（Phase 1から）で開始してください。Phase 1の最後にある「読了範囲の申告」を忘れずに。

3. Phase 2の提案が出たら、承認・修正をやり取りして進める（判断は1つずつ聞いてくる設計になっています）

## パックの中身

- `00-request.md` — 依頼文（ミッション・3フェーズ・働き方ルール）
- `01-context-and-principles.md` — プロダクト原則と判断基準
- `10-ux-feedback/` — 6/30整理済みのUX改善仕様パック一式（コピー）
- `11-source-materials/0629meeting.md` — ミーティング文字起こし原文（全文読解テストを兼ねる）
