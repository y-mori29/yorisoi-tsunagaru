# よりそい つながる コミュニティ説明インフォグラフィック

作成日: 2026-06-24
用途: プレゼン資料・説明資料にそのまま貼れる画像スライド

## スライド一覧

1. `01-overview.png`
   - 「よりそい つながる」全体像
   - 読む、探す、近い部屋で読む、声を置く、保存・反応する流れ

2. `02-user-value.png`
   - ユーザー側の価値
   - まず読める、近い声に出会える、比べなくてよい、書ける時だけ置ける

3. `03-main-functions.png`
   - 主要機能
   - 読む、探す、部屋で読む、声を置く

4. `04-main-screens.png`
   - 主要画面
   - ホーム、探す、部屋、声を置く、保存した声、安心設定

5. `05-writing-experience.png`
   - 書く体験
   - ひとこと、体験談、聞いてみる、自分だけメモと置き場所

6. `06-topic-data-design.png`
   - 病気・症状・不安を広く受け止める設計
   - 検索、自由入力、診断前、裏側の保存、近い部屋への案内

7. `07-safety-and-growth.png`
   - 安心して使えるための設計
   - 医療判断ではない、登録前閲覧、個人情報、強い言葉、通知、次に育てること

## デザイントーン

- やさしい水彩
- 温かい紙質背景
- ココアブラウンの手描き線
- モスグリーン、テラコッタ、淡いプラムのアクセント
- 患者さん向けの安心感を保った、説明資料用の落ち着いたトーン
