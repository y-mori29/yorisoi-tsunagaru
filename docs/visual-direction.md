# ビジュアル方針

作成日: 2026-05-16
位置づけ: キービジュアル・キャラクター・カラー・トーンの方針。CodexCLIで画像生成する際の指針になる。

## ゴール

> **「アイコンを見ただけで、ちょっとホッとする」**
>
> ─ 病気を抱えていてもなお、毎日アプリを開きたくなる温度感をビジュアルで担保する。

## ベンチマーク

| サービス | 何を学ぶか |
|---|---|
| **GRAVITY（グラビティ）** | 優しさ・匿名でも「人らしい」温度・パステル × ふんわり |
| **あすけん** | 専門家アイコン（栄養士の未来さん）の親しみやすさ |
| **Calm / Headspace** | 不安を煽らない配色・アニメーション・余白の取り方 |
| **Mindcare系アプリ** | 「医療っぽくない」がちゃんと信頼できる、絶妙なバランス |

## カラーパレット（暫定）

「医療系」によくある **白×水色×グレー** は **避ける**。冷たい・病院っぽい・続かない。

### プライマリ：やわらかいピーチ × 抹茶クリーム

- **ピーチ系**: `#FFD9C7` / `#FFB89A` / `#FF8E70`
- **抹茶クリーム系**: `#E8F0D9` / `#C7DBA8` / `#9BB87A`
- 理由：あたたかみと、「植物が育つ」ような成長・回復のイメージ

### セカンダリ：くすみラベンダー（夜・休息）

- `#E0D6E8` / `#B8A8C9` / `#8E7AA0`
- 理由：夜の時間帯・休息モード・落ち着いた投稿に使う

### アクセント：マスタードイエロー（喜び・通知）

- `#F5C84A`
- 通知バッジ・「気づき」を生んだ瞬間など、特別なポジティブ要素のみに使う

### グレー（テキスト）

- 黒は使わない。`#2E2A2A`（暖かみのあるダークブラウン）をベーステキストに

→ **「曇った日の朝、家でハーブティを飲んでいる」** 配色をイメージ

## キャラクター案

### A案：擬人化動物キャラ（推奨）

医療っぽさを消し、感情移入しやすくするための「水先案内人」キャラ。

候補：
1. **🐰 ふわふわのうさぎ** — 弱さも見せていい安心感
2. **🐻 もこもこの熊** — 抱きしめてもらえる温度感（ベンチマーク：くまモン的だが医療版）
3. **🐱 アンニュイな猫** — つかず離れずの距離感（ベンチマーク：グラビティのキャラに近い）
4. **🌱 もこもこの森の妖精** — 生き物に紐づかない柔らかさ

→ **3〜4案で迷い中**。最初は **複数のキャラが森に住んでいる世界観** にして、ユーザーが選べる形もアリ。

### B案：抽象シンボル

キャラを置かず、グラデーション円・ふわふわ雲・揺れる光のアニメーションで温度を出す。

→ A案推奨。キャラがいる方が「会いに来た」感が出る。

## イラストトーン

- **線**：細め・手描き感あり・完璧でない揺れ
- **塗り**：水彩・グラデーション・ベタ塗りしない
- **背景**：ふんわりした粒子・光・余白多め
- **避ける**：シャープ・ベクター完璧・3DCG・無機質・テック系

### 参考スタイル

- 絵本「ぐりとぐら」「11ぴきのねこ」のあたたかさ
- 大野舞・ヨシタケシンスケ系のイラストエッセイ
- Instagramの「ほっこり系イラストレーター」の世界観
- ジブリ作品の背景画（特に「魔女の宅急便」のキキの部屋）

## タイポグラフィ

### 日本語

- **ヒラギノ角ゴ Pro W3** / **Noto Sans JP Regular** をベース
- 見出しは少し丸い系：**ヒラギノ丸ゴ Pro W4** / **Zen Maru Gothic**
- 太字は最小限（脅迫的に見える）

### 数字・英字

- **Inter** または **Noto Sans** Regular
- 数字は等幅にしない（医療っぽくなる）

### サイズ感

- 本文：16px（小さすぎない・読みやすい）
- 行間：1.7〜1.8（ゆったり）
- 文字色：`#2E2A2A`（暖グレー） on `#FFFCF8`（オフホワイト）

## アニメーション

- すべて **イージング** をかける（リニアでカクカクしない）
- ボタンタップ：軽く膨らんで戻る（春らしい弾み）
- 通知到着：ふわっとフェードイン
- 投稿成功：キャラが小さくお辞儀するなど、感情のあるリアクション
- ローディング：呼吸するような明滅（不安を煽らない）

## 避けるNG表現

- 🚫 救急車・点滴・カルテ・聴診器などの「病院アイコン」
- 🚫 真っ赤・真っ青などの強いカラー
- 🚫 「治る！」「効く！」など効果効能の断言
- 🚫 ビフォーアフター系の表現
- 🚫 シャープなフォント（明朝体・ゴシックBlack）
- 🚫 「闘病」「克服」などの戦闘メタファー
- 🚫 体重・血圧などの数値を画面の主役にしない

## ブランド名・ロゴ

- **名称：よりそい つながる**
- 「よりそい」ブランドを継承しつつ、人と人がゆるく「つながる」場、というメッセージ
- ロゴモチーフ候補：
  - 2つの円がやさしく重なるアイコン（ベン図的だが角を完全に丸める）
  - 並んで歩く2つの足跡
  - 枝が触れ合う2本の若木
  - 寄り添う2つの葉
- フォントは丸ゴシック系（**Zen Maru Gothic** / **ヒラギノ丸ゴ**）で温度感を出す
- 「よりそい」と「つながる」の間は **半角スペース** を入れる正式表記
- ローマ字表記：`yorisoi tsunagaru`（フォルダ名・リポジトリ名はハイフン `yorisoi-tsunagaru`）

## CodexCLI生成プロンプト方針

`prompts/` 配下に置く構造化プロンプトmdは、以下を必須にする：

```yaml
---
title: <name>
category: keyvisual / logo / character / icon / illustration / mood
output: assets/images/<filename>.png
size: 1024x1024 / 1024x1792 / 1792x1024
style_tags: [warm, watercolor, soft, hand-drawn, low-contrast]
forbidden: [medical, sharp, neon, red, hospital, clinical, syringe]
---

# Subject
（英語10セクション）
# Composition
# Lighting
# Color palette
# Texture
# Mood
# Negative space
# Style references
# Camera / Perspective
# Avoid

---
# 日本語End note
（日本語で意図と、生成後にチェックしたい点を記述）
```

最初に作るアセット（優先順）：
1. **キービジュアル1枚**（アプリ紹介・LP・MTG共有用）
2. **キャラクター案 3〜4種**（うさぎ・熊・猫・森の妖精）
3. **アプリアイコン候補 3案**
4. **ムードボード3枚**（朝・昼・夜の世界観）
5. **オンボーディング挿絵 5枚**

詳細は `prompts/README.md` を別途整備する。
