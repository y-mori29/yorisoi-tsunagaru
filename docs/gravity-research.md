# GRAVITY（グラビティ）— 「優しいSNS」徹底リサーチ

## 0. このドキュメントの位置づけ

メディキャンバスで「よりそい つながる」（病気を抱える方が安心して使える、続けたいと思える優しいSNS）を新規開発するにあたり、参考とすべきリファレンスとして GRAVITY を分解する。GRAVITY は「SNS疲れに効く / 優しい / 匿名 / 共感」をコアバリューに、4年強で累計 700万DL を突破している希少な成功事例。"なぜ優しさが成立しているか" の構造を明らかにすることが本資料の目的。

---

## 1. アプリ概要

### 提供会社・基本情報
- **運営**：株式会社HiClub（HiClub Inc.）
- **リリース**：2020年12月17日（iOS / Android 同時）
- **累計DL**：
  - 2021年5月：30万DL（リリース5ヶ月）
  - 2022年9月：MAU約30万人
  - 2023年3月：累計250万DL
  - 2024年6月：累計600万DL
  - 2025〜26年：累計700万DL超（biz-memoの分析記事ベース）
  - 公式コピーでは「登録ユーザー500万人超」「10百万DL超」と表記される媒体もあり、媒体ごとに数字がブレるが**700万DL前後が直近値**として有力。
- **メイン層**：20代女性中心（2022年データで20代が53.6%、男女比ほぼ1:1）。Z世代の「SNS疲れ」勢が主要ペルソナ。
- **位置づけ**：「やさしいSNS」「癒されるSNS」「共感で繋がるSNS」。Twitter/Instagramのように"映え"や"バズ"を目的化せず、**匿名で気の合う人と気軽に話せる場所**を志向。

### "優しいSNS" と呼ばれる所以（一行サマリ）
> 「フォロワー数・拡散・自撮り・実名」という従来SNSの"競争装置"を**意図的に全部外した**設計に、性格診断とニッチコミュニティを上から載せている。優しさは思想ではなく**仕様の積み重ね**で生まれている。

## 2. UI/UX上の主な特徴

### 2-1. 投稿の仕組み
- **テキスト**：300〜1,000文字程度（媒体ごとに表記揺れ。記事によっては「300字以下」「1000字以下」）。**Twitterより長く、ブログより短い** "つぶやき+α"の粒度。
- **画像・60秒動画・ハッシュタグ・音楽（BGM紐付け）・音声・位置情報**を添付可能。
- **公開範囲を投稿ごとに選べる**：全体公開／フォロワーのみ／友達のみ。 → 「とりあえず吐き出したいけど全世界には見せたくない」需要を吸収。
- **リポスト（RT）機能なし**。 → "バズらせる"動機が構造的に発生しない。
- **アカウント検索を許可しない設定**が可能。 → リアル知人からの身バレ防止。

### 2-2. フィードの仕組み
- **タイムライン**は「全ユーザー（おすすめ）」と「フォロワー」の切り替え式。
- **「みつける（探索）」タブ**：ランダムに他ユーザーのページを訪問できる。"出会い直し"が常時発生する作り。
- **「宇宙探索」**：興味カテゴリで投稿を絞り込める発見導線。
- **「星の予報」**：性格診断ベースで"共感してくれそうな人"を自動レコメンド。
- **「惑星（プラネット）」/ 趣味の星**：音楽の星・ゲームの星など共通話題のコミュニティ。タイムラインはここに紐付く。**フォロー駆動ではなくトピック駆動**のフィードがハイブリッドで動いている。

### 2-3. リアクション・コメント
- **「いいね」あり、ただし"誰が押したか他フォロワーに通知されない"**。 → いいね合戦・観測されている圧から解放。
- **コメント可**。Androidは一部返信不可など端末差あり。
- **共感スタンプ中心の設計**（2026年マーケ記事）で、数値の積み上げによる承認競争を回避。
- **足あと機能**（誰が見たか）はあり、有料プランで拡張可能。

### 2-4. 画面トーン・配色・キャラクター要素
- **宇宙モチーフ**で世界観を統一。「星」「惑星」「宇宙通話」「星粒」「星と交信」「心友ノック」など、機能名がすべて宇宙語彙で揃っている。 → **メタファーが一貫しているのでUIが説明を必要としない**（"フォロー"より"心友"の方が温度感が伝わる）。
- 配色は**ダーク基調＋宇宙のパステル**（紫・青・ピンクのグラデ）。"治安の悪いSNSのギラギラ" でも "ビジネスSNSのフラット白"でもない、**夜空のような穏やかさ**。
- イラストは丸みのある**サンリオ寄りのかわいさ**ではなく、**「ふわっと中性的な宇宙人」風**。性別・年齢を匂わせない。

### 2-5. アイコン・アバター・プロフィール
- **自撮り・実写NG。運営提供のイラストアバターのみ選択可能**。 → "盛り写真"も"加工バトル"も発生しない。
- **アイコンスロット／アイコン装飾**（ガチャ的に集めるアバター装飾）あり。**「装飾で自己表現」**を許容しつつ、顔写真には行かせない設計。
- プロフィールは**性格診断結果（外的性格／内的性格）とタグで表現**。**外的性格は全公開、内的性格は相互フォロー（=心友）のみ可視**という二段階開示。
- **生年月日以外の個人情報登録なし**。誕生日は他ユーザーに非開示。
- **フォロー数・フォロワー数を他ユーザーから確認できない**。 → 「100人にフォローされてる人 vs 3人の人」という格差が画面上に存在しない。

## 3. 「優しさ」「安心感」を生んでいる工夫（中核）

### 3-1. 匿名性の扱い（"匿名"の解像度が高い）
GRAVITYの匿名は単に「ハンドルネーム」ではなく、**多層構造**：
1. **個人情報**：メアドのみで登録、生年月日も非開示
2. **見た目**：実写NG、運営アバター固定
3. **可視メトリクス**：フォロワー数・いいね押した人 非表示
4. **検索性**：ユーザー検索を拒否できる
5. **公開範囲**：投稿ごとに3段階で切替

→ "誰にも特定されないが、共感してくれる誰かには届く" 状態を **5層で担保**。

### 3-2. 攻撃的投稿への対処（モデレーション実装）
- **通報機能**：プロフィール／チャット／投稿のどこからでも通報可能。
- **ブロック機能**：ワンタップで完全遮断。
- **AIによる日次パトロール＋人力レビュー**。違反内容により**アカウント停止／シャドウBAN**。
- **公開セキュリティレポート**を月次でnoteに発信（2025年10月分で**13,640件のアカウント停止**）。違反TOP3は「性的内容」「詐欺の恐れ」「攻撃的内容」。 → **"運営が動いている"を可視化**することで安心感を醸成。
- **15歳未満禁止**を明記。なりすまし・画像送信誘導・外部アプリ誘導はTOS違反として明確化。

### 3-3. 弱音・悩みを吐き出しやすい設計
- **「星と交信（質問箱）」**：話題を投げてそれに関心を持った人が拾う**受動的コミュニケーション**。 → 自分から知人に絡まなくて済む。
- **「心友ノック」**：性格診断16タイプベースで"考え方の近い人"を見つけ、ノックを送ってつながる。 → 「趣味の一致」ではなく**「考え方の癖の近さ」**でマッチング。これは患者向けSNSで非常に重要な発想。
- **AIパートナー**：AIに悩み相談できる導線。**いきなり人に相談するハードルを段階的に下げる**。
- **NPO連携**：認定NPO法人カタリバ（2024年8月）、ReBit（2024年11月）に寄付。**メンタルヘルス文脈で社会性を提示**。

### 3-4. 新規ユーザーが孤立しない仕組み
- **登録直後に16性格診断**を実施。 → 登録完了時点でレコメンド精度が立ち上がる。
- **「星の予報」**で初日から共感してくれそうな相手が提示される。
- **「みつける」**でランダム遭遇が常時発生。 → "誰もフォローしていないから何も流れない"という冷たいタイムラインが発生しない。
- **質問箱が1日1回**配信される設計で、**毎日1回は誰かが話しかけてくれる**機会を運営が作っている。

### 3-5. 通知設計
- 静かな通知設計で「常時確認の前提がない」（2026年koukoku.jp記事）。
- いいねした人は通知されない（前述）が、**自分の投稿への反応は通知される**。 → 反応が来ない不安より、来た時の喜びを重視。
- **これは継続のドライバーになっている**：「全体公開で弱音を吐く → 知らない誰かが優しいコメント → 通知で気づく → また来る」の継続ループが、競争のないままに回る。

## 4. コミュニティ促進の工夫

### 4-1. ルーム / コミュニティ機能
- **惑星（プラネット）**：趣味カテゴリのコミュニティ。「音楽の星」「ゲームの星」「悩みの星」など。フォローではなくトピックで集まる。
- **音声ルーム**：2〜6人のグループ音声通話。顔出しなし。**Clubhouseのカジュアル版**のような体験。
- **トーク（DM）**：相互フォロー（心友）でのみ可能。 → DMハラスメントの構造的予防。

### 4-2. ユーザー同士のつながり方
- フォロー＝「心友」と呼称する（**用語が温かい**）。
- 性格診断ベースのマッチング（心友ノック）。
- 質問箱／星と交信での受動的接触。
- 音声ルーム／宇宙通話での偶発的会話。

### 4-3. 「いま誰かが見てくれる」感の演出
- **宇宙通話**：匿名ユーザーとランダムマッチして、5分（プロフィール公開なら15分）の音声通話。 → "誰かが聞いてくれる即時性"を担保。
- **ペット育成「iUぷらねっと」**：ログイン継続インセンティブ。
- **足あと機能**：誰かに見られた、を可視化（プレミアム拡張あり）。
- **公開セキュリティレポート**：運営の"見守り"が見える。

## 6.「よりそい つながる」への示唆

### 6-1. ここがすごい・盗みたい（◎=必須採用、○=採用検討）

| 観点 | GRAVITY の仕様 | 「よりそい つながる」での示唆 |
|---|---|---|
| ◎ | 匿名の多層化（個人情報×見た目×メトリクス×検索×公開範囲） | "疾患を持っている"こと自体がセンシティブ情報。**5層構造をそのまま輸入**すべき |
| ◎ | フォロワー数・いいね押者の非表示 | 患者間の"症状の重さで比較される"を絶対に発生させない |
| ◎ | リポストなし | 「あの人の闘病ツイートをバズらせる」事故を構造的に排除 |
| ◎ | 公開範囲を投稿ごとに3段階 | "主治医のみ"／"同病の人のみ"／"全体" の3段階に翻訳可能 |
| ◎ | 月次セキュリティレポート公開 | 患者コミュニティは"運営が見てくれている"が継続の生命線。**透明性は競争優位** |
| ◎ | 性格診断ベースのマッチング（"考え方の癖の近さ"） | 「同じ疾患」だけでなく **「闘病スタンスの近さ」** でマッチさせると効く（前向き／淡々／不安寄り 等） |
| ○ | 用語の温かさ（フォロー→心友、ホーム→宇宙） | "フォロー"を**「お見舞い」「並走者」**等に翻訳。疾患専用語彙の世界観統一 |
| ○ | 質問箱 / 星と交信（受動的コミュニケーション） | 弱音を投げて拾われるUX。「**今日のしんどい**」を匿名で投げて誰かが寄り添う |
| ○ | AIパートナーで悩みを段階的に話す | 人と話す前に**AIが一次受け**。患者の心理障壁を下げる |
| ○ | NPO連携・寄付の発信 | 患者会・疾患団体と連携した社会性訴求が信頼に直結 |
| ○ | 宇宙通話（即時マッチの音声） | "今しんどい人と今しんどい人"を**短時間（5分）でつなぐ**。長電話にしないことが優しさ |
| ○ | アバター装飾の経済 | 顔写真でなく**装飾で自己表現**。患者向けでも自己表現欲求は強い |

### 6-2. 病気を抱える患者向けにアレンジするなら、どこを変えるべきか

**変えるべき点**：

1. **マッチングの軸**
   - GRAVITY：16性格診断（MBTI）
   - 「よりそい つながる」：**疾患 × ステージ × 闘病スタンス**の3軸。同じ疾患でも「治療中／寛解／看取り」で必要な共感は違う。**性格診断は副軸**として残してもよい。

2. **音声機能の慎重な実装**
   - GRAVITY の宇宙通話は出会い目的の悪用が顕在化（セキュリティレポート参照）。
   - 医療文脈では**音声は「患者会オープンルーム」**として運営オフィシャル開催に絞り、1on1ランダムマッチは**初期実装しない**ことを推奨。

3. **未成年・脆弱性配慮の強化**
   - GRAVITY は15歳未満禁止。
   - 医療系は**小児慢性疾患・難病の若年層を排除できない**。**保護者連携モード**や**医療者見守りモード**を新設。

4. **メンタル悪化検知**
   - 自殺念慮等のキーワード検出→専門相談窓口の即時案内（よりそいホットライン等）を**AIモデレーションでGRAVITYより一段強化**。

5. **広告モデルは廃止 or 厳格化**
   - 患者属性で広告ターゲティング = 倫理リスク。**サブスク＋医療機関提携モデル**に寄せる。

6. **「心友」の温度感の翻訳**
   - 闘病文脈に合う固有語彙を設計（"並走者""お守り"等）。**宇宙メタファーをそのまま使うのは違和感**。**「同じ波を抱える人」「灯台」**のような医療と相性の良い世界観を新規構築。

### 6-3. 裾野が広いGRAVITY vs 特定疾患向け「よりそい つながる」— 何を残し何を捨てるか

**残すもの（裾野が広くても本質的に効くもの）**：
- 匿名の多層構造
- 数値競争の排除（フォロワー/いいね数の非表示）
- リポスト不在
- 質問箱型の受動的コミュニケーション
- 性格診断的なマッチング思想（"考え方の近さ"）
- 月次セキュリティレポートの透明性
- 用語の温かさによる世界観統一
- アバター文化（顔写真不在＋装飾経済）

**捨てる／変えるもの（疾患特化なら不要 or 害）**：
- 宇宙モチーフ（疾患文脈には合わない）
- 1on1ランダム音声通話（悪用リスク）
- 広告モデル
- ギフティング（患者間の経済的負担を作らない）
- ペット育成等のエンゲージメントギミック（**真摯さを損なう恐れ**。ただしログイン継続には別の工夫が必要）
- "趣味の惑星"のような汎用興味カテゴリ（**疾患×ステージ×テーマ**に置換）

**新規に足すもの（医療特化で必須）**：
- 主治医／医療者の招待・閲覧モード
- 治療記録（服薬・症状・心拍 等）の任意連携 → タイムラインに自動投稿される"今日の身体ログ"
- 緊急時の専門相談窓口導線（自殺予防、希少疾患患者会、患者ホットライン）
- 家族／保護者の連携モード
- "今日はしんどくて何も書けない"を**ボタン一発で投稿**できる機能（弱音の最低エネルギーUX）
