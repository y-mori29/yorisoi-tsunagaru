# よりそい つながる 残り画面の改築計画

作成日: 2026-06-24
対象: `medicanvas/yorisoi-tsunagaru`

## 背景

ホーム、探す、病気・症状・不安の選択、近い声の表示はかなり形になってきた。

一方で、まだ古い設計をそのまま残している画面がある。

特に、マイページ、ブックマーク、投稿画面は、いまの「登録前でも近い体験談を読み、必要な時だけそっと声を置ける場所」という方向性に合わせて再整理する必要がある。

## すぐ直した点

- 登録画面から名前欄を外した。
- ホーム投稿に閲覧数を追加した。
- 探す画面で、病気・症状・悩みを複数選択し、近い投稿を見られるようにした。
- 下部ナビを固定表示にして、スクロール後も押せるようにした。
- マイページのデモ用「もりさん」表記を外した。

## マイページ

### 課題

- 旧プロフィール画面の構造が残っている。
- 現在のコミュニティ体験では、プロフィールよりも「自分の状態」「読んだ声」「保存した声」「置いた声」が重要。
- 名前や自己紹介を前面に出しすぎると、SNS感や個人特定の不安が出る。

### 方針

マイページは「自分の居場所を整える画面」にする。

優先して見せるもの:

- 自分の病気・症状・不安
- 最近読んだ声
- 保存した声
- 自分が置いた声
- 公開範囲と安心設定

弱めるもの:

- 大きなプロフィール表示
- 名前やハンドルの強調
- 自己紹介の長文
- SNS的な実績表示

### 次の実装

1. プロフィールカバーを小さくする。
2. `自分の病気・症状・不安` カードを主役にする。
3. `最近読んだ声` と `保存した声` を追加する。
4. `自分が置いた声` は下部に移動する。

## ブックマーク

### 課題

現状は `/me/voices` がブックマーク導線のように使われており、意味がずれている。

「自分の投稿」と「保存した声」は別物。

### 方針

ブックマークは「あとで読み返す声」にする。

表示するもの:

- 保存した投稿
- 近い部屋
- 後で読もうと思った体験談
- 読むだけで安心できた声

### 次の実装

1. `/bookmarks` か `/me/bookmarks` を作る。
2. 下部ナビのブックマークをそこへ向ける。
3. 既存の `/me/voices` は「自分が置いた声」に役割を戻す。

## 投稿画面

### 課題

投稿画面は良くなってきたが、まだ「どこに置かれるか」「何の文脈で置かれるか」が少し分かりにくい。

病気・症状・不安を選んだ状態があるなら、それを投稿文脈として自然に使うべき。

### 方針

投稿画面は「投稿する」よりも「いまの気持ちを、どの文脈にそっと置くか」を選ぶ画面にする。

必要な要素:

- 今の気持ち
- 紐づく病気・症状・不安
- 置く場所: 全体 / 近い声 / 部屋 / 自分だけ
- 投稿後に、どの文脈に置いたかが分かる完了表示

### 次の実装

1. 投稿完了後の表示を追加する。
2. `選んだ病気・症状・不安に紐づけました` を明示する。
3. 投稿文脈をあとから変更できる導線を検討する。

## 探す画面

### 今回の方向性

探す画面は、部屋へ行くためだけの画面ではなく、近い投稿を絞り込む画面として扱う。

病気、症状、悩みを複数選択し、その選択に近い声を読む。

部屋は「深く読みたい時のまとまり」として補助的に扱う。

## 優先順位

1. マイページの再整理。
2. ブックマーク画面の役割分離。
3. 投稿完了後の文脈表示。
4. 部屋詳細の説明改善。
5. 体験談データ由来の投稿更新ロジック。
